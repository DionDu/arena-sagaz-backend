# ── Inferência: a CNN do Pontinhos ───────────────────────────────────────────
# `ai-edge-litert` é o runtime AUTÔNOMO do LiteRT (o sucessor do
# `tflite-runtime`): ele carrega o `.tflite` e executa, e é só isso que sabe
# fazer. É a mesma biblioteca C que o `tflite_flutter` embrulha no aplicativo —
# e é por isso que os números batem.
#
# ⚠️ A VERSÃO ESTÁ PRESA DE PROPÓSITO, e mexer nela tem portão. A T001 mediu, em
#    09/09/2026, que a 2.2.0 reproduz número por número a saída do
#    `tensorflow.lite` 2.21.0 que o app usa (o registro está em
#    `docs/historico_decisoes.md`). Trocar esta linha sem rodar
#    `scripts/conferir_runtime_inferencia.py` calibraria o desafio contra um
#    adversário que NÃO é o adversário que a pessoa enfrenta — e nada no sistema
#    denunciaria. O `Dockerfile.job` roda essa conferência no build justamente
#    para que esquecer não seja possível.
ai-edge-litert==2.2.0

# `numpy` monta o tensor de entrada (1, 4, 3, 12) segundo o contrato de
# codificação. Vem junto com o LiteRT de qualquer forma; declarar a versão aqui
# é o que impede uma resolução silenciosa diferente da que foi medida.
numpy==2.2.6
